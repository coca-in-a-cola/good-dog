# GOOD DOG

Godot 4.7.x Forward+ / GDScript psychological horror, PC Windows and Linux. Implemented so far: only the portable `addons/command_overlay` addon and its demo (original phase 1 / F1, awaiting acceptance). No gameplay exists yet.

Tests: `godot4 --headless --path . -s res://tests/run_tests.gd` · portability: `godot4 --headless --path . -s res://tools/portability_test.gd`.

Audio (F5): regenerate sounds `godot4 --headless --path . -s res://tools/audio/synth_f5.gd` then `godot4 --headless --path . --import` · measure the mix `godot4 --headless --path . -s res://tools/audio/mix_capture.gd -- res://evidence/f5`.

Documentation: [index](docs/README.md). Integration branch: `develop`. No source GDD or operational evidence may be published without a separate rights check.
